# Resources

Reference material to support threat hunting operations on pfSense.

## Suggested Contents

- **ioc_list.txt** — Known malicious IPs, domains, and file hashes
- **known_good_hashes.txt** — SHA256 hashes of known-good pfSense binaries by version
- **notes.md** — Case notes, investigation timeline, findings log
